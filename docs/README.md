# Docs Artifact Index

This folder stores progressive SDLC artifacts generated by agent workflows.

## Folder Map
- strategy: strategic scope, priorities, goals
- ux: flows, wireframes, interaction behaviors
- requirements: user stories, acceptance criteria, DoR/DoD
- architecture: blueprints, boundaries, design trade-offs
- api: contracts, schemas, error models, versioning notes
- planning: delivery plans, dependencies, milestones
- testing: test strategies, scenarios, quality gates
- reviews: quality findings and verification notes
- security: threat findings, mitigation requirements
- compliance: controls and evidence plans
- performance: budgets, profiling plans, findings
- operations: runbook and observability specs
- release: rollout plans, rollback criteria, release checks
- documentation: information architecture and doc plans
- knowledge: decision logs, traceability maps, glossary entries

## Naming
Use one file per work item:
- <work-item>.md

Example:
- architecture/checkout-v2.md
- requirements/checkout-v2.md

## Progressive Update Pattern
Append updates using dated section headers:
## 2026-05-18 - Initial draft
## 2026-05-21 - Review updates
